О проекте

«Моё Радио» — современное Android-приложение для прослушивания онлайн-радиостанций с открытым исходным кодом. Включает базу из более чем 2500 радиостанций, сохраненную локально для быстрого и независимого доступа без ожидания сетевых запросов.

Ключевые возможности

  • Офлайн-каталог станций: мгновенный доступ к списку без задержек сети.
  • Умная фильтрация и поиск: поиск по названию станции и группировка по жанрам.
  • Избранное и история: сохранение любимых станций и быстрый возврат к недавним прослушиваниям.
  • Динамическая подсветка (Android Palette Library): карточки радиостанций плавно адаптируют акцентный цвет под преобладающий оттенок логотипа станции.

Гибкая тема Material Design 3 (M3)

Архитектура темы спроектирована с легкой интеграцией цветовых схем, сгенерированных через плагин Material Theme Builder (M3). Поддерживаются как Светлая (Light), так и Тёмная (Dark) темы в различных режимах контрастности и доступности:

  • Стандартный контраст (Standard): сбалансированная фирменная палитра Material Design 3.
  • Средний контраст (Medium Contrast): повышенная четкость для лучшей читаемости на солнце.
  • Высокий контраст (High Contrast): максимальный уровень контраста элементов для пользователей с особенностями зрения.
  • Динамические цвета (Dynamic Colors / Monet): автоматическая генерация всей палитры приложения на основе фонового рисунка рабочего стола (обоев) устройства.

Продвинутая нижняя шторка (Мини-плеер)

Интерактивный плеер спроектирован на базе жестов с жесткими точками прилипания (AnchoredDraggable) и плавно раскрывает элементы по мере выдвигания:

1. Controls (Всегда доступно)

Компактный бар управления: мини-логотип текущей радиостанции и быстрый переключатель Play/Pause.

2. Info (Детальная информация)

Блок подробного описания радиостанции с автоматическим вертикальным скроллом для длинных текстов.

3. Extra Buttons (Быстрые действия)

Панель быстрых переходов: добавление в «Избранное» (дублирует действие на карточке) и кнопка перехода на официальный веб-сайт радиостанции.

4. Volume (Индивидуальный уровень)

Специальный регулятор громкости для тонкой подстройки уровня звука конкретного радиопотока.
