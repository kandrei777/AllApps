Privacy Policy for Easy Calculator Pro

Last updated: September 23, 2026

This Privacy Policy describes how the Easy Calculator Pro mobile application (hereinafter referred to as the "Application") handles user information.

1. Collection and Use of Personal Data

Easy Calculator Pro is a fully offline, local calculation tool.

  • The Application does not collect, track, store, or share any personal user information, location data, contacts, or personal files stored on your device with third parties.
  • All calculations, history logs, and user configurations are stored strictly on the user's local device within the secure application sandbox and are permanently deleted when the Application is uninstalled.

2. Device Permissions

The Application only requests the core Android operating system permissions necessary for its basic mathematical and UI functionality (such as managing the soft keyboard or saving session states). These permissions are never used to access private user data.

3. Third-Party Advertising and Analytics

The Application does not contain any third-party ad networks, telemetry trackers, or background analytical tools that monitor user behavior or collect hardware identifiers.

4. Changes to This Privacy Policy

We may update our Privacy Policy from time to time. You are advised to review this page periodically for any changes.

5. Contact Us

If you have any questions or suggestions regarding the privacy of this Application, please feel free to contact us via email at: andrei.kulik@bellsoft.ru
