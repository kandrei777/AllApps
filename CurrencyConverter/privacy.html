Политика конфиденциальности

Последнее обновление: 1 октября 2026 г.

Разработчик Кулик Андрей (andrei.kulik@bellsoft.ru), далее — «Разработчик», заботится о конфиденциальности пользователей своего мобильного приложения-конвертера валют (далее — «Приложение»). Данная Политика конфиденциальности объясняет, как Приложение взаимодействует с информацией.

1. Сбор и использование персональных данных

Приложение спроектировано по принципу offline-first и работает полностью локально на вашем мобильном устройстве.

  • Приложение не собирает, не запрашивает, не хранит и не передает третьим лицам никакую личную информацию пользователей (такую как имя, адрес электронной почты, номер телефона или информацию о местоположении).
  • В Приложении отсутствует функция регистрации, поэтому все пользовательские настройки (выбранные темы оформления, порядок валют в списке) хранятся исключительно в памяти вашего собственного устройства.

2. Запросы к сторонним сервисам (API)

Для обеспечения своей основной функции — конвертации валют — Приложение загружает актуальные курсы обмена из открытого источника: сайта freecurrencyrates.com.

  • Этот запрос выполняется исключительно с целью получения актуальных котировок валют.
  • В процессе запроса к API стороннему сайту не передаются никакие личные или идентифицирующие пользователя данные.

3. Реклама и аналитика

  • Приложение не содержит встроенной рекламы (рекламные идентификаторы AdID/IDFA не используются).
  • Приложение не использует сторонние сервисы аналитики или сбора отчетов об ошибках (такие как Google Analytics, Firebase, Amplitude и др.).

4. Безопасность данных

Поскольку Приложение не собирает персональные данные в сети Интернет и не хранит их на удаленных серверах, риск утечки вашей конфиденциальной информации исключен. Безопасность локальных данных в памяти устройства обеспечивается стандартными механизмами защиты операционной системы Android.

5. Контакты

Если у вас возникли вопросы или предложения относительно работы Приложения и защиты данных, вы можете связаться со мной напрямую по электронной почте: andrei.kulik@bellsoft.ru.

Privacy Policy

Last Updated: October 1, 2026

Developer Andrei Kulik (andrei.kulik@bellsoft.ru), hereinafter referred to as the "Developer", cares about the privacy of the users of their mobile currency converter application (hereinafter referred to as the "Application"). This Privacy Policy explains how the Application interacts with information.

1. Collection and Use of Personal Data

The Application is designed based on the offline-first approach and operates entirely locally on your mobile device.

  • The Application does not collect, request, store, or share with third parties any personal information of users (such as name, email address, phone number, or location data).
  • There is no registration feature in the Application, so all user settings (selected color themes, currency order in the list) are stored exclusively in your own device's memory.

2. Third-Party API Requests

To provide its core function — currency conversion — the Application downloads up-to-date exchange rates from an open source: the freecurrencyrates.com website.

  • This request is performed solely to retrieve current currency quotes.
  • No personal or user-identifying data is transmitted to the third-party website during the API request.

3. Advertising and Analytics

  • The Application does not contain integrated advertising (advertising identifiers like AdID/IDFA are not used).
  • The Application does not use third-party analytics services or crash reporting tools (such as Google Analytics, Firebase, Amplitude, etc.).

4. Data Security

Since the Application does not collect personal data online and does not store it on remote servers, the risk of your confidential information leaking is eliminated. The security of local data in the device's memory is ensured by the standard protection mechanisms of the Android operating system.

5. Contact Information

If you have any questions or suggestions regarding the operation of the Application and data protection, you can contact me directly via email: andrei.kulik@bellsoft.ru.
